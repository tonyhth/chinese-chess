> 版本：v1.1（Vera 审查修复版）| 作者：Alex | 日期：2025-06-09
> ⚠️ 前置方案 v2.1（AI 图像生成方案）已废弃。原因：CogView-3-Flash 无法保证 6 色风格一致性。
> 本方案采用纯 Pillow 程序化生成，确保像素级风格一致。

## 一、基础体型参数（所有角色共用）

画布 1024×1024，角色居中。

| 参数 | 值 | 说明 |
|------|-----|------|
| 身体中心 cx, cy | 512, 547 | 略偏下，留出配饰空间 |
| 身体 rx, ry | 360, 265 | 横向宽、纵向扁的椭圆（宽高比 ≈ 1.36:1） |
| 渐变方向 | 上浅下深 | 从上到下 linear gradient |
| 边缘抗锯齿 | 边缘 5% alpha 渐变 | `edge_alpha = min(1.0, (1.0 - abs(dx_norm)) / 0.05)` |
| 脚半径 | 50px | 两个椭圆，中心 y = cy + ry - 30，左右偏移 ±95 |
| 眼睛 y 位置 | cy - 55 | 位于上半身 |
| 眼睛 rx, ry | 38, 34 | 椭圆形 |
| 眼睛间距 | ±75（从中心） | |
| 瞳孔半径 | 24 | 略偏右下（+4, +2） |
| 腮红 y 位置 | 眼睛 y + 48 | |
| 腮红 rx, ry | 25, 15 | 椭圆 + 高斯模糊 6px |
| 嘴巴 y 位置 | 眼睛 y + 68 | |
| 高光椭圆 | body 左上方 | [cx-180, cy-180, cx+40, cy-40]，alpha=50，模糊 20px |
| 投影 | body 下方 | [cx-rx+80, cy+ry, cx+rx-80, cy+ry+20]，alpha=30，模糊 10px |

## 二、6 角色颜色定义

### 2.1 身体渐变色

逐像素计算公式（来自丹妮 v4 脚本）：
```
t = (py - (cy - ry)) / (2 * ry)  # 0=top, 1=bottom
light = 1.0 - t * 0.12           # 上亮下暗
r = min(255, int((r_top - r_delta * t) * light))
g = min(255, int((g_top - g_delta * t) * light))
b = min(255, int((b_top - b_delta * t) * light))
```

| 角色 | r_top | g_top | b_top | r_delta | g_delta | b_delta | 脚色 RGB |
|------|-------|-------|-------|---------|---------|---------|----------|
| **yellow** | 255 | 230 | 110 | 40 | 55 | 40 | (255, 200, 80) |
| **pink** | 255 | 200 | 210 | 40 | 55 | 50 | (255, 170, 190) |
| **blue** | 160 | 210 | 255 | 30 | 45 | 40 | (120, 180, 230) |
| **green** | 170 | 240 | 170 | 40 | 55 | 40 | (130, 210, 130) |
| **red** | 255 | 160 | 150 | 40 | 50 | 40 | (255, 120, 110) |
| **black** | 140 | 140 | 145 | 50 | 50 | 50 | (100, 100, 105) |

### 2.2 腮红参数

所有角色统一腮红：
- 颜色：`(255, 130, 130, 120)`
- 大小：rx=25, ry=15
- 模糊：GaussianBlur(6)

### 2.3 配饰定义

**配饰必须和身体颜色有高对比度。配饰尺寸要足够大（120pt 显示时仍可辨认）。**

#### egg_yellow — 金色小皇冠
```
位置: cx=body_cx, cy=body_cy - body_ry + 20
宽度: cw=75, 高度: ch=55
形状: 3 尖角锯齿形（polygon）
填充: (255, 200, 0) 金色
描边: (200, 160, 0) 深金色, 2px
装饰: 中央一颗红色宝石 (220, 50, 50)，半径 7
```

#### egg_pink — 深粉色蝴蝶结
```
位置: body_cx + 40, body_cy - body_ry - 10（偏右，在身体上方）
大小: 左翼 60x45, 右翼 60x45, 中心结 18x18
填充: (220, 50, 100) 深玫红色（和粉色身体拉开色差）
描边: (180, 30, 70) 更深玫红, 2px
形状: 两个三角/椭圆翅膀 + 中间小圆结
```

#### egg_blue — 白色水手帽
```
位置: body_cx, body_cy - body_ry + 15
帽顶: 圆角矩形 160x70, 白色 (245, 245, 255)
帽檐: 扁椭圆 180x25, 深蓝 (30, 60, 140)
帽带: 水平线 160x8, 深蓝 (30, 60, 140)
装饰: 帽子正面一个小锚标志（简化为 T 形）, 深蓝
```

#### egg_green — 深绿小草芽
```
位置: body_cx - 15, body_cy - body_ry - 20（偏左上方）
两片叶子:
  左叶: 椭圆旋转 -30°, rx=12, ry=35, (50, 160, 50)
  右叶: 椭圆旋转 +20°, rx=10, ry=30, (60, 180, 60)
描边: (30, 100, 30), 2px
茎: 短竖线, (60, 120, 40), width=4
```

#### egg_red — 金色星星发卡
```
位置: body_cx + 60, body_cy - body_ry + 30（右上方）
形状: 五角星, 外径 32, 内径 14
填充: (255, 210, 0) 金黄色
描边: (200, 160, 0), 2px
发卡杆: 短竖线, (200, 160, 0), width=3
```

#### egg_black — 深灰恶魔角
```
位置: body_cx ± 50, body_cy - body_ry - 5
左角: 三角形, 顶点向左上偏, (60, 20, 20) 暗红
右角: 三角形, 顶点向右上偏, (60, 20, 20) 暗红
描边: (40, 10, 10), 2px
大小: 宽 35, 高 45
```

## 三、5 种表情状态差异

### 3.1 idle（默认）
- 眼睛：白底 + 黑瞳孔 + 2 个白色高光
- 嘴巴：微笑弧线 `arc(start=10, end=170)`, width=4, color=(80, 60, 40)
- 无特殊

### 3.2 happy（开心）
- 眼睛：**闭眼弯月形**——用 `arc` 画向下弯的弧线（不是椭圆），白色填充宽度 6-8px
  - 左眼: `arc(x-30, y-10, x+30, y+10, start=200, end=340)` 
  - 右眼: 同上，x 偏移
- 嘴巴：更大的微笑 `arc(start=5, end=175)`, width=5
- 腮红：略大（alpha 提升到 150）

### 3.3 excited（兴奋）
- 眼睛：**金色五角星瞳孔**
  - 眼睛尺寸放大：rx=44, ry=40
  - 瞳孔替换为金色五角星：外径 28，内径 12
  - 填充：(255, 210, 0) 金黄色
  - 高光 3 个白色点（在星星外）
- 嘴巴：**大 O 形张嘴**——用椭圆替代弧线
  - 椭圆 rx=22, ry=18, 黑色填充 (40, 30, 30)
  - 内部一个粉色舌头 (240, 140, 140) 小椭圆
- 腮红：alpha 提升到 160（更红）

### 3.4 sad（难过）
- 眼睛：正常大眼但 **瞳孔向下偏移**（+8px），眼神失焦
  - 瞳孔位置：偏下 (+8) 且偏内 (-2)
  - 高光只保留 1 个（显得无神）
- **泪滴**：左眼外角一滴水滴形
  - 位置：左眼 x - 30, 眼睛 y - 5
  - 形状：椭圆 (12, 14) + 下端尖角（polygon）
  - 颜色：(180, 210, 240, 220) 半透明浅蓝（较高效不透明度）
- 嘴巴：**倒弧线** `arc(start=190, end=350)`, width=4
- 眉毛：两条短弧线在眼睛上方，向内下弯（八字眉）
  - 颜色：(60, 50, 40, 180), width=3

### 3.5 mini（迷你版）
- **整体缩放到 60%**（不是重新绘制，是将 idle 版缩小后放到 512×512 画布中央）
- 缩放后画布：512×512（@2x 实际为 512×512）
- 细节自然被缩小，无需额外简化
- 表情固定为 idle

## 四、输出规格

| 状态 | @1x 尺寸 | @2x 尺寸 | 格式 |
|------|---------|---------|------|
| idle/happy/excited/sad | 512×512 | 1024×1024 | PNG RGBA |
| mini | 256×256 | 512×512 | PNG RGBA |

文件大小实际范围（程序化生成无背景残留，天然较小）：
- @2x idle/happy/excited/sad：39-54KB
- @2x mini：25-30KB
- @1x：对应 @2x 的约 1/3~1/4

命名：`egg_{color}_{state}.png` / `egg_{color}_{state}@2x.png`

输出目录：`~/DevTeam/projects/vocab-game/character-gen/`
