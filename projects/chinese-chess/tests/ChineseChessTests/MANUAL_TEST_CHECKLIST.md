# 手动测试清单 — 中国象棋 macOS 应用

## 基本交互

- [ ] 启动应用，棋盘正常显示（木纹背景、棋盘线条、楚河汉界、棋子）
- [ ] 点击任意红方棋子，出现金色选中高亮
- [ ] 选中后显示绿色可走位置标记
- [ ] 点击绿色标记的空位，棋子移动到目标位置（有动画）
- [ ] 点击绿色标记的对方棋子，吃子成功，被吃棋子消失
- [ ] 点击非法位置，选中取消，无移动
- [ ] 黑方回合时点击红方棋子无响应

## AI 对战

- [ ] 红方走完后，AI（黑方）自动响应
- [ ] AI 思考时状态栏显示"AI 思考中"脉冲动画
- [ ] AI 思考时棋盘不可点击
- [ ] AI 走棋后棋盘更新正确

## 难度切换

- [ ] 初级：AI 走法随机，响应极快
- [ ] 中级：AI 走法有基本策略
- [ ] 高级：AI 思考时间较长，走法更优

## 功能按钮

- [ ] 新局：棋盘重置为初始局面，所有状态清空
- [ ] 悔棋：撤销玩家 + AI 各一步，棋盘恢复
- [ ] AI 思考中时新局和悔棋按钮禁用

## 状态栏

- [ ] 显示当前轮次（红方/黑方走棋）
- [ ] 显示回合数
- [ ] 被吃棋子正确记录并显示
- [ ] AI 思考时显示思考中状态

## 游戏结束

- [ ] 将死时弹出游戏结束弹窗，显示获胜方
- [ ] 弹窗有"再来一局"按钮
- [ ] 点击后棋盘重置

## 视觉

- [ ] 棋子为圆形，有立体感（渐变 + 阴影）
- [ ] 红方棋子为红色楷体字，黑方为黑色楷体字
- [ ] 选中棋子有金色光晕
- [ ] 棋子移动有平滑动画
- [ ] 九宫格斜线正确显示
- [ ] 兵/卒和炮位有星位标记

## 完整对局

- [ ] 开局走 5 步（含普通移动和吃子），每步确认交互正常
- [ ] 确认 AI 每步走法合法
- [ ] 将死一方后游戏正确结束
