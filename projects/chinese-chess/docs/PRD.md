# 产品需求文档：中国象棋 macOS 原生应用

## 项目概述
开发一款 macOS 原生的中国象棋游戏，支持人机对战，中国风视觉设计。

## 技术要求
- **平台**: macOS 原生应用（Swift + SwiftUI）
- **最低系统**: macOS 14.0+
- **架构**: MVVM，代码整洁可维护
- **AI**: 内置象棋 AI（至少支持初级/中级/高级三个难度）
- **语言**: Swift

## 功能需求

### 核心功能
1. **棋盘渲染**: 标准 9×10 中国象棋棋盘，楚河汉界
2. **棋子**: 红黑双方各 16 枚棋子，标准规则移动
3. **走棋规则**: 完整实现所有棋子的移动规则（将/帅、士/仕、象/相、马、车、炮、兵/卒）
4. **人机对战**: 玩家执红先行 vs AI（黑方）
5. **AI 难度**: 三个级别（初级随机/中级启发式/高级 Minimax + Alpha-Beta 剪枝）
6. **胜负判定**: 将死/困毙判定，自动结束
7. **悔棋**: 支持悔棋操作
8. **新局**: 随时开始新对局

### 视觉设计（中国风）
1. **棋盘**: 木纹质感，传统配色
2. **棋子**: 圆形立体棋子，红黑双色，楷体字
3. **配色**: 温暖的木质色调 + 传统中国红/墨黑
4. **动画**: 棋子移动动画、吃子动画
5. **音效**: 落子、吃子音效（可选）

### 交互
1. 鼠标点击选子 → 高亮可走位置 → 点击目标位置移动
2. 移动合法性实时校验，非法走法提示
3. 状态栏显示：当前轮次、被吃棋子、走棋历史

## 交付物
1. **设计文档**: 架构设计、类图、模块划分、AI 算法说明
2. **源代码**: 完整可编译运行的 Xcode 项目
3. **测试用例**: 单元测试（走棋规则、AI 逻辑）+ 集成测试
4. **README**: 编译运行说明
