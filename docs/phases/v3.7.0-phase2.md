## 一、AnalysisViewModel 集成 FENRebuilder

### 现状
`AnalysisViewModel.computeFEN(before:)` 直接返回 `initialFEN`，无论 index 是多少。分析结果完全错误。

### 修改方案

```swift
// AnalysisViewModel.swift

// 新增 fenList 缓存
private var fenList: [String] = []

// 替换现有的 computeFEN(before:) 方法
private func computeFEN(before index: Int) -> String {
    guard index >= 0 && index < fenList.count else { return initialFEN }
    return fenList[index]
}

// load() 签名扩展
func load(moves: [String], initialFEN: String, gameMoves: [GameMove]) {
    self.moves = moves
    self.initialFEN = initialFEN
    self.analyses = Array(repeating: nil, count: moves.count)
    self.currentIndex = 0
    // 预计算 FEN 列表
    self.fenList = FENRebuilder.computeAllFENs(initialFEN: initialFEN, moves: gameMoves)
}
```

### 调用方改动
`AnalysisView.startAnalysis()` 中需要传 gameMoves：

```swift
let gameMoves = replayVM.record.moves
analysisVM.load(moves: iccsMoves, initialFEN: fen, gameMoves: gameMoves)
```

## 三、导出功能 UI 集成

### 3.1 导出方式

| 方式 | 触发 | 格式 | 说明 |
|------|------|------|------|
| 复制到剪贴板 | 回放页按钮 / 列表长按 | PGN 文本 | 通用 |
| 系统分享面板 | 回放页分享按钮 / 列表分享按钮 | PGN 文件 | iOS Share / macOS NSSharingService |
| 文件导出 | 回放页"导出"按钮 | .pgn 文件 | 保存到 Files / 指定路径 |

### 3.2 段位门禁

**导出需翰林段位，导入无限制。**

```swift
enum UnlockedFeature: String, Codable, CaseIterable {
    // ... 已有 case ...
    case gameRecordExport    // 棋谱导出（翰林）
    case gameRecordImport    // 棋谱导入（无段位限制）

    var requiredRank: Rank {
        switch self {
        // ... 已有映射 ...
        case .gameRecordExport:    return .hanlin
        case .gameRecordImport:    return .novice   // 无段位限制
        }
    }
}
```

导出按钮可见性：
- 未解锁时显示锁定提示（翰林解锁），不隐藏按钮
- 点击锁定按钮 → 显示升级提示

```swift
var canExport: Bool {
    PlayerProfileStore.shared.profile.isFeatureUnlocked(.gameRecordExport)
}
```

### 3.3 ReplayView / AnalysisView 改造

标题栏右侧增加 ↗ 分享按钮：
- 复制 PGN 到剪贴板
- 分享（系统分享面板）
- 导出为文件

### 3.4 GameHistoryView 改造（仅导出相关）

- 单条：swipeActions 增加"分享"按钮
- 单条：contextMenu 增加"导出PGN"/"复制棋谱"

### 3.5 批量导出

GameHistoryView 多选模式：
- toolbar "选择"按钮 → 批量导出/删除
- 使用 PGNExporter.exportBatch() 合并为一个 PGN 文件

### 3.6 PGN 文件写入

导出为 .pgn 文件时：
- 文件名格式：`{title}_{date}.pgn`（如 `人机对弈_2026.06.29.pgn`）
- iOS：通过 UIActivityViewController 分享
- macOS：NSSharingService 或直接保存到指定路径
