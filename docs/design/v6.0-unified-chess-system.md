## 一、产品愿景

用户打开 App → 棋力评估（分析对局估算 Elo）→ 推荐合适的级别（1-10）→ 在该级别对弈 → 积累数据 → 评估精度提升。

两个功能本来就是一个闭环，合并设计、合并评审、合并发布。

## 二、10 级棋力梯度

### 2.1 核心架构

```
级别 1-5：自研 AIEngine（走法像人，棋力 ~600-1800）
级别 6-10：Pikafish Skill Level（天梯校准，棋力 ~1280-3300）

EngineRouter 按难度自动路由
```

### 2.2 为什么不用 depth 控制棋力

depth 限制搜索树深度，低 depth 时行为非单调（depth 1 只搜 quiescence，反而比 depth 2 强）。Skill Level 是完整搜索后按概率选劣变，可控且有天梯校准数据。

## 三、棋力评估功能

### 3.1 目标

帮用户定位棋力水平，推荐合适的对弈级别。不依赖用户对弈各级别（用户连最低级别都赢不了），而是通过分析对局质量估算 Elo。

### 3.2 六维评估体系

| 维度 | 评估方法 | 数据来源 | 权重 |
|------|---------|---------|------|
| **棋力等级（Elo）** | 逐手走法 delta 分布拟合 | PositionAnalyzer | 核心 |
| **开局水平** | 前 15 步与 OpeningBook 匹配率 | OpeningBook | 15% |
| **中盘战术** | 精妙/好/普通/失误/漏着 占比 | PositionAnalyzer 六级标注 | 25% |
| **残局功底** | 残局走法质量 + 胜率 | EndgameEvaluator | 20% |
| **稳定性** | 逐手 delta 序列标准差 | delta 序列分析 | 20% |
| **杀棋敏感度** | 将杀机会发现率 | CheckmateSearch | 20% |

### 3.3 Elo 估算原理

对每步走法计算与引擎推荐最优走法的 delta（centipawn）：

```
保守公式：Elo = 2500 - 120 × ln(平均 delta)
置信度：< 40 步 = low，40-79 步 = medium，≥ 80 步 = high
95% CI：±150 Elo（high confidence 时）
```

### 3.4 评估流程

```
用户进入"棋力评估"
├── 方式 A：新对弈 vs 3级（业余初级），1-3 局
├── 方式 B：分析历史对局（最近 5 局 vs AI）
│
└── 逐手分析（PositionAnalyzer 批量分析，0.6s/步）
    ├── Elo 估算（±150 置信区间）
    ├── 六维雷达图
    ├── 优势/短板分析
    ├── 推荐对弈级别（映射到 1-10 级）  ← 直接输出到 10 级选择
    └── 推荐训练方向
```

### 3.5 推荐级别映射

| Elo 范围 | 推荐级别 | 说明 |
|----------|---------|------|
| < 800 | 1级（入门） | 能赢 1 级再升级 |
| 800-1100 | 2级（初级） | — |
| 1100-1400 | 3级（业余初级） | — |
| 1400-1700 | 4级（业余中级） | — |
| 1700-2000 | 5级（业余高级） | — |
| 2000-2300 | 6-7级 | Skill Level 区间 |
| 2300-2700 | 8级（业余五段） | — |
| 2700+ | 9-10级 | 专业级 |

## 四、技术实现

### 4.1 AIDifficulty 枚举改造

```swift
enum AIDifficulty: String, CaseIterable, Codable {
    // 业余级（自研引擎）
    case novice        // 1级 入门
    case beginner      // 2级 初级
    case amateurLow    // 3级 业余初级
    case amateurMid    // 4级 业余中级
    case amateurHigh   // 5级 业余高级

    // 专业级（Pikafish Skill Level）
    case amateurDan    // 6级 业余初段 (Skill 0)
    case proApprentice // 7级 业余三段 (Skill 4)
    case proExpert     // 8级 业余五段 (Skill 8)
    case proMaster     // 9级 专业三段 (Skill 13)
    case grandmaster   // 10级 棋圣 (Skill 20)

    var isProfessional: Bool { ... }
    var skillLevel: Int? { ... }
}
```

### 4.2 EngineRouter 路由

业余级 → 自研 AIEngine；专业级 → Pikafish + Skill Level。Pikafish 不可用时 fallback 到自研 master。

### 4.3 评估数据模型

```swift
struct StrengthReport: Codable {
    let eloEstimate: EloEstimate       // Elo + 置信区间
    let recommendedLevel: AIDifficulty // 推荐级别（直接映射 10 级）
    let dimensions: SixDimensionScores // 六维评分
    let moveStats: MoveStatistics      // 逐手统计
    let strengths: [String]            // 优势
    let weaknesses: [String]           // 短板
    let trainingSuggestions: [TrainingSuggestion]
}
```

### 4.4 设置页 UI

```
Section("业余级") {
    Picker: 1-5 级
}
Section("专业级") {
    Picker: 6-10 级
}
Section("棋力评估") {
    Button("开始评估") → 评估流程
    if let report = lastReport {
        六维雷达图 + Elo + 推荐级别
    }
}
```
