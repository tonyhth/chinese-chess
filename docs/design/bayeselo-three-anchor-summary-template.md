填数规则：
- W-D-L 以**锚点方**（高 Skill/高 lvl 一侧）为视角，与 BayesElo Δ 同向
- 胜率 = (W + 0.5D) / 局数；BayesElo Δ = -400·log10(1/胜率 − 1)（实现：SelfPlayRunner.swift:1214 BayesElo）
- 先手胜率 = 红方胜局/总局；§七口径 >50% 记先手优势显著（A34 40.0% = 无先手偏置）
