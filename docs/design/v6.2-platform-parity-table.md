# v6.2 双平台行为对照表（`#if os()` Parity Table）

> 产出于 Vera HIG 审计 P2-1（`docs/design/v6.2-hig-audit-vera.md` §P2，原文计 70 处；本表按 v6.2 tip 实核为 **75 处 = Views 72 + App 3**，增量来自 08 后新增分支）。
> 口径：`grep -rn "#if os(" src/ChineseChess/Views/ + src/ChineseChess/App/`，v6.2 tip `b1cf39f`。
> 用途：发布说明、快修链、双平台一致性回归的参照物。**非机制**，不建检查流程（Vera 定案）。
>
> 差异原因分类（五类，[平台适配] 为 08-25 Ruby 审后补声明——介于必然与布局之间的平台惯例差异，如 macOS 定宽 sheet、iOS 系统反馈补偿、平台 bug 规避）：
> - **[平台必然]** SwiftUI/AppKit/UIKit API 或交互范式差异（HIG 要求），无法统一
> - **[平台适配]** 平台惯例差异：非 API 硬约束，但按平台惯例有意为之（macOS 定宽 sheet、iOS 复制反馈补偿、macOS SwiftUI bug 规避）
> - **[布局适配]** 同功能因屏幕尺寸/窗口模型采用不同信息架构，语义一致
> - **[平台专有]** 功能仅单平台成立（剪贴板 API、触觉反馈、键盘快捷键等）
> - **[待统一]** 无必然理由的不一致，后续版本可收敛（本表制表时为零目标，新发现按此标注）
>
> **排除范围声明**：本表口径锁 Views+App（75 处）。全库另有 21 处 #if os() 不在表内（SoundEngine 5 / SelfPlayRunner 5 / PlatformExtensions 3 / EmbeddedPikafishEngine 2 / GameViewModel、PuzzleViewModel 等 VM/Services/AI 各 1，共 21：SoundEngine 5 / SelfPlayRunner 5 / PlatformExtensions 3 / EmbeddedPikafishEngine 2 / GameViewModel、PuzzleViewModel、FontRegistry、CMAESOptimizer、TranspositionTable、OpeningBookExpander 各 1）——其中 GVM/PuzzleVM 两处属用户可感知行为面，待 Luke 裁定是否 v6.2 内入表，其余为引擎/音频内部实现非行为对照面。
