## 二、P0 清单（10 项 — 必须修复）

### 架构（D1）— 3 项
1. **Models 反向依赖 Services**（8 文件）— Board 调 FENParser、6 个 Model 调 L10n、DailyChallenge 调 PuzzleStore。违反单向依赖原则。
2. **GameViewModel 缺失 halfmoveClock**（50 回合规则）— 已有三次重复/困毙/长将检测，独缺这一项，和棋检测不完整。
3. **iOS 端 Sheet 管理未统一** — macOS 已修的 P0 bug（多 .sheet 串联导致卡死），iOS 仍有 14 个独立 .sheet。

### 并发安全（D2）— 1 项
4. **C 层 g_engine 全局单例并发竞争** — PositionAnalyzer 和 EmbeddedPikafishEngine 通过 withCheckedContinuation + DispatchQueue.global 跳出 actor，两个后台线程完全并发进入 C 层，actor 隔离无效。可导致结果错乱或 Use-After-Free 崩溃。
   - 推荐方案：短期 A（统一调用入口）+ 中期 C（C API 多实例化）

### 国际化（D4）— 2 项
5. **`feature.gameRecordImport` xcstrings key 缺失** — UnlockedFeature.swift 引用不存在的 key，英文用户看到 raw key。
6. **macOS CommandMenu 硬编码中文** — "引擎"/"配置引擎" 硬编码，英文用户菜单栏看到中文。

### 测试（D5）— 4 项
7. **UnifiedSheetTests 过时** — SheetDestination 已 15 个 case，测试只验 12 个，v3.7.2 新增的 analysis/coach/openingExplorer 完全裸奔。
8. **和棋检测伪覆盖** — DrawDetectionIntegrationTests 5 个测试全部伪覆盖（`if...{#expect(true)}else{#expect(true)}` 结构性不可能失败），且算法是测试内重新实现的副本而非调用实际代码。
9. **`isSafeCapture` 永远返回 false** — CoachExplainer.swift:206，导致 `.missedCapture` 教学路径完全静默（六分之一的教练提示类型永不触发）。
10. **13 个源文件零测试覆盖** — 含 AI 核心 KingSafetyEvaluator(235行) 和 OpeningBookExpander(283行)。

## 三、P1 清单（39 项 — 建议修复）

### 关键 P1（跨维度关联）
- **TT 内存 ~350MB/实例 × 多 AIEngine 实例**（D6）↔ **PuzzleViewModel 直接创建 AIEngine 而非复用 EngineRouter**（D1）— 同一根因，既是内存浪费也是模块边界问题
- **ZobristHash 每个 negamax 节点全量重算**（D6）— 增量方法已存在但未用，增加 15-25% 搜索时间
- **findRecordByPuzzleId 磁盘全量扫描**（D2+D6 双维度指向）— RecordSummary 已有 puzzleId，内存匹配即可
- **CheckmateSearch maxResponses=8 剪枝**（D6）— 残局排局高概率超 8 应将，影响 AI 防守判定
- **PositionAnalyzer 硬编码 struct 偏移量**（D6）— 内存安全隐患
- **PatternRecognizer.bonusPatterns() 202 行**（D3）→ Ruby 复核降 P2（棋类调度表模式合理）
- **boardFingerprint() 重复实现**（D3）— GameViewModel vs PuzzleViewModel
- **多个 >50 行函数**（D3）— triggerAIMove(121行)、movePiece(113行)、renderOverlays(106行) 等
- **棋盘尺寸魔法数字 9/10/8 散布**（D3）
- **BoardTheme 主题名/解锁条件硬编码**（D4）
- **PGN 导出/导入 ~15 处硬编码**（D4）
- **AIEngine displayName 硬编码**（D4）— 已有 xcstrings key 却没用
- **174→153 个 xcstrings key 未被引用**（D4）— 主要为预留 key
- **PreferencesMigration 仅 macOS 初始化**（D1，从 P0 降级）— iOS 实际不受影响但缺注释
- **EndgameEvaluator 84 条规则无测试**（D5）
