# tacticalGroup 标注规则

> 适用分类：车马炮类（212局）、车炮类（88局）
> 标注方法：启发式规则（基于 solution 步数 + 名称关键词）

## 分类定义

| 子分类 | 含义 |
|--------|------|
| 杀势 | 直接杀法，短解法连将致胜 |
| 弃子攻杀 | 包含弃子战术的长解法，先弃后取 |
| 催杀 | 连续将军或威胁迫使对方被动，中等长度 |
| 困毙 | 对方无合法走法但未被将军（或和棋残局） |
| 其他 | 不符合以上分类的特殊局 |

## 标注规则（按优先级）

### 1. 名称关键词修正（最高优先级）

| 关键词 | 标注 |
|--------|------|
| 困、鼠、穴、陷、牢、囚、虎出穴 | 困毙 |
| 弃、舍、抛 | 弃子攻杀 |
| 催、逼、迫、驱 | 催杀 |

### 2. Solution 步数规则

| 步数 | 标注 | 说明 |
|------|------|------|
| 0 | 杀势 | 无解法（freePlay 或特殊局），与车马炮类一致 |
| 1-2 | 杀势（含"和"→困毙） | 极短解法 |
| 3-12 | 杀势 | 短/中短解法，直接杀 |
| 13 | 困毙 | 车马炮类13步全部为困毙 |
| 14 | 杀势 | 边界情况 |
| ≥15 | 弃子攻杀 | 长解法，涉及弃子战术 |

### 3. 车马炮类特例

车马炮类的标注（commit f4ae1b2）使用了更精细的规则，其中步数 11 和 13 存在杀势/催杀、困毙/催杀的分歧，需要人工判断。当前标注已通过 30 局抽样核验（85% 确认合理）。

## 后续改进

1. **Pikafish 精确标注**：用 Pikafish 分析 solution 终局特征（对方被将死→杀势，对方无合法走法→困毙等），替代启发式规则
2. **催杀细分**：当前车炮类无催杀标注，步数 11-13 的局可能包含催杀，需人工确认
3. **其他类扩展**：其他大分类（车炮类以外的分类）如有需要，可按相同规则标注
