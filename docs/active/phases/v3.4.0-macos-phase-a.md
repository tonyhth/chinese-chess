# Phase A：预编译 libpikafish.a + modulemap + NNUE Bundle 打包

> macOS 静态库嵌入 — 第一步：准备预编译静态库、Swift 模块映射、NNUE 资源打包
>
> 依赖：iOS 引擎集成（Phase 1-6）完成
> 工期：1 天
>
> ⚠️ **NNUE 修正（2026-06-26）**：pikafish 不支持编译时 NNUE 嵌入。`-DNNUE_EMBEDDING_ON` 是无效参数。
> NNUE 以 zstd 压缩文件形式打包到 App Bundle Resources，运行时由 `pikafish_api.cpp` 通过
> `CFBundleCopyResourcesDirectoryURL` 加载。详见 `nnue-embedding-investigation.md`。

---

## 目标

1. 创建构建脚本，预编译 pikafish 为多平台静态库
2. 创建 modulemap，使 Swift 能直接 `import Pikafish`
3. 将 `pikafish.nnue` 打包到 App Bundle Resources
4. 在 Xcode 项目中集成静态库 + NNUE 资源，验证编译链接通过
5. 记录编译环境和 pikafish 版本

## 详细实施

### A.1 构建脚本

```bash
#!/bin/bash
# Pikafish/build.sh — 预编译 pikafish 静态库
# ⚠️ NNUE 不嵌入静态库，以独立文件打包到 App Bundle Resources
set -euo pipefail

# === 编译环境锁定 ===
REQUIRED_XCODE="16.2"
REQUIRED_MACOS_SDK="15.2"
DEPLOYMENT_TARGET_MACOS="13.0"
DEPLOYMENT_TARGET_IOS="16.0"
OPTIMIZATION="-O3"

# === 配置 ===
PIKAFISH_SRC="${1:?Usage: build.sh <pikafish-source-dir>}"
SCRIPT_DIR="$(cd "$(dirname "$0")" && pwd)"
OUTPUT_DIR="$SCRIPT_DIR"

# NNUE 文件——拷贝到项目 resources 目录，打包到 App Bundle
NNUE_FILE="${PIKAFISH_SRC}/../pikafish.nnue"
if [ ! -f "$NNUE_FILE" ]; then
    echo "错误：NNUE 文件不存在: $NNUE_FILE"
    echo "pikafish.nnue 必须存在于 Pikafish/ 目录中"
    exit 1
fi

# 记录 pikafish 版本
PIKAFISH_COMMIT=$(cd "$PIKAFISH_SRC" && git rev-parse --short HEAD)
PIKAFISH_DATE=$(cd "$PIKAFISH_SRC" && git log -1 --format=%cd --date=short)
CLANG_VERSION=$(clang --version | head -1 | awk '{print $NF}')
XCODE_VERSION=$(xcodebuild -version | head -1 | awk '{print $2}')
SDK_VERSION=$(xcrun --show-sdk-version --sdk macosx)

# === 拷贝 NNUE 文件 ===
mkdir -p "$OUTPUT_DIR/resources"
cp "$NNUE_FILE" "$OUTPUT_DIR/resources/pikafish.nnue"
echo "NNUE 文件已拷贝到: $OUTPUT_DIR/resources/pikafish.nnue ($(du -h "$NNUE_FILE" | cut -f1))"

# === 编译函数 ===
build_pikafish() {
    local target=$1 arch=$2 platform=$3 deploy_target=$4 output_dir=$5
    
    echo "Building for $platform ($arch)..."
    mkdir -p "$output_dir"
    
    make -C "$PIKAFISH_SRC" clean 2>/dev/null || true
    make -C "$PIKAFISH_SRC" build \
        ARCH="$arch" \
        COMP=clang \
        TARGET="$target" \
        CXXFLAGS="${OPTIMIZATION} \
                  -target ${arch}-apple-${platform}${deploy_target}" \
        LDFLAGS="-target ${arch}-apple-${platform}${deploy_target}" \
        -j$(sysctl -n hw.ncpu)
    
    cp "$PIKAFISH_SRC/build/libpikafish.a" "$output_dir/libpikafish.a"
    make -C "$PIKAFISH_SRC" clean
}

# === 编译各平台 ===
# iOS device (arm64)
build_pikafish arm64 arm64 iphoneos "$DEPLOYMENT_TARGET_IOS" "$OUTPUT_DIR/lib/ios"

# iOS simulator (arm64)
build_pikafish arm64 arm64 iphonesimulator "$DEPLOYMENT_TARGET_IOS" "$OUTPUT_DIR/lib/ios-sim-arm64"

# iOS simulator (x86_64)
build_pikafish x86_64 x86_64 iphonesimulator "$DEPLOYMENT_TARGET_IOS" "$OUTPUT_DIR/lib/ios-sim-x86_64"

# iOS simulator universal
mkdir -p "$OUTPUT_DIR/lib/ios-sim"
lipo -create \
    "$OUTPUT_DIR/lib/ios-sim-arm64/libpikafish.a" \
    "$OUTPUT_DIR/lib/ios-sim-x86_64/libpikafish.a" \
    -output "$OUTPUT_DIR/lib/ios-sim/libpikafish.a"

# macOS (arm64)
build_pikafish arm64 arm64 macosx "$DEPLOYMENT_TARGET_MACOS" "$OUTPUT_DIR/lib/macos-arm64"

# macOS (x86_64)
build_pikafish x86_64 x86_64 macosx "$DEPLOYMENT_TARGET_MACOS" "$OUTPUT_DIR/lib/macos-x86_64"

# macOS universal
mkdir -p "$OUTPUT_DIR/lib/macos"
lipo -create \
    "$OUTPUT_DIR/lib/macos-arm64/libpikafish.a" \
    "$OUTPUT_DIR/lib/macos-x86_64/libpikafish.a" \
    -output "$OUTPUT_DIR/lib/macos/libpikafish.a"

# 清理中间产物
rm -rf "$OUTPUT_DIR/lib/ios-sim-arm64" "$OUTPUT_DIR/lib/ios-sim-x86_64" \
       "$OUTPUT_DIR/lib/macos-arm64" "$OUTPUT_DIR/lib/macos-x86_64"

# === 写入 VERSION ===
cat > "$OUTPUT_DIR/VERSION" <<EOF
PIKAFISH_COMMIT=${PIKAFISH_COMMIT}
PIKAFISH_DATE=${PIKAFISH_DATE}
BUILD_MACOS_VERSION=$(sw_vers -productVersion)
BUILD_XCODE_VERSION=${XCODE_VERSION}
BUILD_CLANG_VERSION=${CLANG_VERSION}
BUILD_SDK=macosx${SDK_VERSION}
BUILD_OPTIMIZATION=${OPTIMIZATION}
BUILD_NNUE_EMBEDDING=OFF
NNUE_DEPLOYMENT=Bundle_Resource
MACOSX_DEPLOYMENT_TARGET=${DEPLOYMENT_TARGET_MACOS}
IOS_DEPLOYMENT_TARGET=${DEPLOYMENT_TARGET_IOS}
EOF

echo "Build complete. VERSION:"
cat "$OUTPUT_DIR/VERSION"
```

> **与 v1 的关键差异**：
> - ❌ 删除 `-DNNUE_EMBEDDING_ON`（无效参数）
> - ✅ 增加 NNUE 文件拷贝步骤（`cp pikafish.nnue → resources/`）
> - ✅ VERSION 中 `BUILD_NNUE_EMBEDDING=OFF`，增加 `NNUE_DEPLOYMENT=Bundle_Resource`

### A.5 VERSION 文件

由 `build.sh` 自动生成。`BUILD_NNUE_EMBEDDING=OFF` 标记 NNUE 不嵌入静态库。

### A.6 NNUE 文件拷贝

构建脚本自动将 `pikafish.nnue`（48MB zstd 压缩）拷贝到 `Pikafish/resources/` 目录。

此文件需要加入 Xcode 的 **Copy Bundle Resources** build phase，确保打包到 App Bundle Resources 目录。

### A.7 Xcode 配置

| Build Setting / Phase | 值 |
|-----------------------|---|
| Header Search Paths | `$(SRCROOT)/ChineseChess/Pikafish/include` |
| Library Search Paths | `$(SRCROOT)/ChineseChess/Pikafish/lib/$(PLATFORM_NAME)` |
| Other Linker Flags | `-lPikafish` |
| Copy Bundle Resources | `Pikafish/resources/pikafish.nnue` |

> **iOS 侧**：`project.yml` 已有 `Pikafish/pikafish.nnue` 在 Copy Bundle Resources 中（第 75 行）。macOS 侧需同样配置。

### A.9 验证 NNUE 运行时加载


## 风险点

| 风险 | 影响 | 回退 |
|------|------|------|
| pikafish Makefile 不支持 macOS arm64 编译 | 阻塞 | 手动 clang 命令编译，参考 iOS 编译参数 |
| modulemap 不被 Xcode 识别 | Swift import 失败 | 检查 Header Search Paths，必要时用 bridging header 过渡 |
| NNUE 文件未加入 Copy Bundle Resources | 运行时加载失败 | 确认 Build Phases 中包含 pikafish.nnue |
| `MACOSX_DEPLOYMENT_TARGET` 不一致 | 运行时崩溃 | 构建脚本强制锁定 13.0，`lipo -info` 验证 |
