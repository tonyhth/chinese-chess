## 任务 C0：布局基建（§2 原则落地件）

1. **token/面板规格层**：§2 版式 token（间距/面板宽度档/截断省略规范）落地为共享常量，全后续期引用同一源；
2. **自适应状态机**：窗口宽窄切换用 `background GeometryReader + onChange(of: size)` 喂 @Observable 状态机；**迟滞带 <1000 收 / >1080 展**，标准 debounce；**禁用 onGeometryChange**（部署目标 macOS 14/iOS 17 不达，Ruby R2 实现约束）；
3. **像素锚基建**：截图 harness + **对偶件 LAYOUT_DUMP 参数通道**（Ruby P2-3 口径）——本期只建骨架，P1 页接入。
