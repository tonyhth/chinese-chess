## §4 三门判读（机械判）

### G-M1 → 门过 ✓（附迁移性归因强制随行）

- 门定义：段距 >0 且 ≥100。实测梯度 ≥798（方向正、幅度深超门限）——**门过**。
- **迁移性归因（丹妮点名项）**：历史标定 0→4 = +540 @500ms（n=70，66-2-2，Skill0 胜率和 ~5%）vs R2-P1 全败 ≥798 @5000ms——偏差 +48%。归因链：
  1. **预算口径迁移为主因候选**：5000ms 下 Skill4 搜索深度优势完全兑现（95% 将死、均步 70.9 快速终结），Skill0 的 pick_best 劣变在深度差面前无补偿——500ms 历史口径下双方同浅、劣变互抵，段距被压缩；产品口径还原真实差距。
  2. **统计退化**：0/20 全败使点估退化为上界，+798 与 +540 的差值部分可能来自小样本极端实现——不可作为"段距精确放大 48%"的结论。
  3. **非刻度机理漂移证据**：无同口径反面数据；方向与单调序完全一致。
- **产品面含义（联动姊妹件）**：lvl2（skill0）与 lvl3（skill4）之间空隙 ≥798 >> 感知阈值——**低段插值档（skill 1/2/3）从"条款可选"升为"设计必然"**（姊妹件 §3-⑤ 与 §2.2 段距下限门联动）；保质期条款（偏差 >20% 触发）在本批实证触发——500ms 标定值在产品口径下的引用须加"预算迁移注记"。

## §5 预算-强度交互观察（机理观察项输入，随行不承重）

- 0→4 段：500ms→5000ms 幅度放大（540 → ≥798）；4→7 段：同迁移幅度缩小（352 → 301）——**预算-强度交互在低段显著更陡**。
- 机理候选：低 skill 值的 pick_best 劣变占比大，高预算下强方深度优势兑现后劣变无法补偿（段距拉大）；中高 skill 值双方劣变占比均小、深度优势共享（段距稳定）。
- 与 rootDepth 触发层假说（T-0921-6 观察项）的关系：本批数据为其新增输入面（预算维度），不改变假说挂起态。
- 对重排表的输入：低段梯度陡 → 低段档位密度需求高（插值档必然化）；中段稳定 → 现行三段标定保质期条款延续。
