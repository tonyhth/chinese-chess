**Batch B 各步骤的验证门**：

| ①c | 翻转后 `git status --dry-run` 全量盘点零意外暴露 + verify_delivery 再跑一轮 | Tina |
| ②a/b/c | `git worktree list` 与 WT-REGISTRY 行数一致 + 无 prunable + 主仓/存留 worktree 构建不受影响（主仓构建门一轮） | Tina |

**执行纪律（KI 案沉淀，全部沿用不变）**：
1. **旗标预热/测试同带**（dda033a Tina 裁定：构建指纹不匹配=强制重编=宏 flake 回归）；
2. **前台执行**——夜间批次须白名单化后才可后台，当前纪律下正式批一律前台（bbdc2f9 四象限口径：唯前台+豁免绿）；

**免卡含义的边界**：白名单解决的是"授权卡超时/用户不在场"，**不豁免 flock 互斥、预检、对账门规**——runner 内置纪律原样有效，Batch B 各批照走。
