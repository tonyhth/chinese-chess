## §2 方案 B 四要素逐项评估

### ① 主轴回归 Pf Skill 序刻度（0→4→7→10）

- **证据面**：成立。三段标定复核终版（n=60/70/30 合并）是全项目唯一过复核的强度梯度数据；单调性双背书（官方序刻度+本地实测）。
- **载体含义（关键）**：自研 AIEngine 无 skill 旋钮——主轴回归 Pf 刻度在工程上**等价于 lvl2-5 载体切换 Pikafish**。产品面后果=10 级体系整体重排（skill 0-20 全刻度化，现行 lvl6-10 锚点〔纸面 v2.1：4/7/10/13/20；实码 v4.2 remap：0/4/7/10/20，见 §1.3 前提勘误〕与 lvl2-5 的 0/4/7/10 锚点重叠，必须连续化重排）。**此为方案 B 的实质而非副作用，须在定案时显式确认**（候选重排形态示意，非定案：lvl1 教学档豁免 + skill 0/1/2/4/6/8/10/13/16/20 或同级距形态，具体由难度体系 v2.2 设计件承载）。
- **一致性收益**：与现行专业档同构（同为 skill 刻度），消除"业余档自研/专业档 Pikafish"双层刻度并行的体系性分裂——10 级单一刻度化。

### ② config(hard/med) 降风味选项退出校准表

- **证据面**：成立，且是实测必然。config 桥是 Y2' 交错结构的核心承重轴，探针实测 X₂=+34.9（d2 域）/ X₃=+17（d3 域）双双 <40 档距下限——config 单差在两个深度域都不可标定档距。退出校准表与 T-1002-3 预登记矩阵"X₂<40 → 桥条件不满足"行一致。
- **产品面语义**：config 差异保留为非梯度"风味选项"（搜索风格，不承担强度档距）。**定义缺口**：风味选项的载体与用户可感性未定义（自研引擎若退役则该项自然消解；若保留自研面则需明确呈现形态）——进 §8 清单。
- **连带**：AIConstants 的 hard/mediumNoQS/simplified 分档在产品面退化为非校准参数， Enums 噪声表/kill 参数等档位映射同步失去梯度职能。

### ③ depth 轴出清

- **证据面**：成立。四证据链（−52.5/−127/−89/−17.4）跨两预算域+TT 双态全负，结构性坐实；hard-d3 在可预见修复路径外不入档（判读 §10 判读词原文）。
- **P3-3 残留边界**：killers/history 排序状态污染未完整排除——但该残留属引擎修复线（若可修也是未来时），弱化链设计不应押注不可控修复；出清决策不受残留影响。
- **连带作废**：Y2' 交错结构的存在前提=「config 桥拆 269 断崖」，depth 出清后交错结构前提消失——v6.5 §3.2 Y2' 表、§4 档距表、断崖/下限缓解链整体失效（幅度见 §4 评估面）。

### ④ L1 豁免维持

- **证据面**：成立。P0 双侧实测（macOS 20/20 和棋；iOS 19 和+1 红胜）→ 校准域零区分度 97.5%，完成性全门 PASS——豁免（教学/体验档定位，不计档距门）依据不变。
- **载体分叉（定案面）**：豁免本身两选项下均成立，但载体不同——a) 维持自研 hard-d1（双引擎架构存续，自研引擎至少教学档保留）；b) Pikafish skill 极低值+约束条件（引擎单一化，自研可整体退役）。两选项产品面差异（行为一致性/打包/叙事）进 §8 定案清单。

## §3 评估面一：产品梯度体感（含 72% 压缩段影响）

### 3.1 段距-体感对照

感知阈值参照（difficulty-system-v2 v2.1 §梯度分析）：**400-500 天梯 Elo 才产生明显"更强"感知**。

| 方案 B 段 | 段距 | 对阈值 | 体感判定 |
|---|---|---|---|
| skill 0→4 | +540 | 超阈值 | 入门→进阶感知清晰 ✓ |
| skill 4→7 | +352 | 低于阈值下沿 | **中段升级感知偏弱 ⚠**（72% 压缩段） |
| skill 7→10 | +352 | 低于阈值下沿 | 中上段感知偏弱（117% 但绝对值同 352） |

### 3.2 三点判断

1. **72% 压缩是刻度固有形状，非方案 B 新增**：现行专业档 lvl7→8 段距 +300（2268→2568）已在产品承担同等偏弱体感，用户面无新增退化；段位命名（三级→二级棋士）+天梯折算数值在 UI 面提供补偿表达。
2. **相对自研面现状是净改善**：自研 lvl1-5 现状=低端断崖+lvl4≈lvl5 顶档无差+lvl2≪lvl4 倒挂——用户在自研面体验到的"升档无感/反向"问题，在单调性有刻度保证的方案 B 下整体消除。体感评估的对照基线是现状，不是理想均匀刻度。
3. **压缩段缓解选项评估**：a) 中段插值加密（skill 5/6 小档）——**反模式，不推荐**：小档距 <300 体感更弱且消耗档位资源；b) 文案/段位补偿——低成本可并行；c) 接受+观察项——与专业档先例一致。**评估倾向 c（接受+观察项），b 可选并行**；压缩根因（rootDepth 触发层假说）定案前不做结构性干预。

### 3.3 低段衔接体感

L1（豁免教学档）→ skill 0 的段距未标定（若 L1 维持自研 hard-d1，跨引擎段距口径不可比——双层校准报告"相对层/绝对层"分离原则）；产品面 L1→L2 的体感下界=P0 实证自研 hard-d1 校准零区分度（极弱）对 skill 0（天梯 1280），方向必然为正且幅度大，体感风险低，但**数值不可预填**（v0.5.1 P3-⑤ 先例：未证断言不写）。
