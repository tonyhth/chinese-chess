## 2. 与 C0/C1 基线的复用与差异

**直接复用**
- LayoutSpec 单源 token：间距四档、字阶三档、面板三档宽、圆角——sidebar 宽度/卡片栅格间距一律引 LayoutSpec，禁散调（C0 铁律延续）。
- 截图 harness + LAYOUT_DUMP 参数通道（C1 基建）：C3 锚图验收直接挂；V64 验收 Registry 模式照 C1 扩展。
- 文案截断规范（单行截断+尾部省略+hover tooltip）适用于 sidebar 分类项与行式列表长文案。

**明确不复用/差异**
- `AdaptiveRailState` 迟滞机**不适用于** C3 sidebar（原则三：NavigationSplitView sidebar 系统托管 columnVisibility，不编程接管）——见 §3 冲突项。
- `GameRailView`/`GameInfoBandView` 是 P1/P3/P4 右通栏辅助面板组件，C3 列表/卡片页无此形态，不复用（防误套）。
- P5/P6 是卡片栅格页，无 sidebar；语言统一靠 token 与卡片规格，非结构统一。
