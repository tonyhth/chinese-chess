**关键算术（v1.1 双框架重述，Vera P2-1）**：本节在两个口径下分别成立，结论一致——
- **严格单差链框架**：每段主差单一，可用档距段 = depth 两台阶 + config 一台阶 = 最多 3 段 < 需 4 段，带内五档直接不可达；
- **整段直测框架**（Y2' 实际工作口径，P1-1 原则精化后）：段距可由对局对整段实测承载（不拆解归因），5 格链存在（med-d1/hard-d1/med-d2/hard-d3 等组合）；但任何 5 格链**必含恰一条 d1↔d2 边**，其段距下界恒断崖——hard-d1→med-d2 = 798−X₂ ≫ 200；med-d1→med-d2 ≈ 798−X₂+X₂@d1 ≈ 598-800（按 X₂@d1<40 自证）。

### 1.3 现状确认：draft 原 Y2 的内在张力（修正动机）

draft v0.4.2 §3.2 备选原文："Y2 = lvl1 hard / lvl2 mediumNoQS"。该定义在单差链口径下**两态皆伤**：
- 若 lvl2 = mediumNoQS-**d1**（同深度）：L1→L2 段距 = X₂@d1，d1 浅树上 QS/eval 差异面更小，大概率 <40，段距不达标；
- 若 lvl2 = mediumNoQS-**d2**：段距=798−X₂ 的同族断崖（深度台阶照过），且比直接用 hard-d2 更弱——**在断崖论证下即不成立，无需引单差链**（P1-1②：本节否定改由断崖承载，零结论损失；单差链表述见原则精化）。

**档距段口径原则（v1.1 P1-1 精化）**：每段主差单一，**或整段直测不拆解归因**——Y2' 全链仅 C 段一个整段直测豁免（归因由 P-C 实测直接承载，这正是 P-C 取代 269−X₃ 推算的方法论价值），最小偏离。

**结论：原 Y2 不能按原文执行；其正确形态是"config 桥拆 269 断崖"的交错排布（本报告 Y2'），L1 端用豁免而非换 config 来处置。**

## 2. 三问评估

### 2.1 Q1：config 齿轮能否提供中间档

**齿轮存在性 ✓**：mediumNoQS 是现产 config 预设，零产品代码；.simplified 同（保留定义在案）。

**可执行性 ✗（现 driver）**：批表 L60 亲验口径——"depth/book/kill 三轴无注入通道，五档由代码隐式控制"。**场景注记（v1.1 P3-②）**：L60 该表述基于"五档预设对"场景；Y2' 需要的 med-d2 / med-d3 交叉格**超出预设对集合**，不在 L60 豁免面内——探针工单必要，勿引 L60 反对。前置 = 双侧 config×depth 交叉注入探针（`--config-a/--depth-a/--config-b/--depth-b` 形态，与 oc-y-probe 已落地的 roleEngineA/B + `--kill-a/--kill-b` 完全同构，估算 ~几十行，探针级不合 m1，先例 = **授权单 a20fab93（授权单号非 commit，台账在案，v1.1 P3-③标注）**）。**此工单是 probe 链的硬前置，呈 Luke 派工**（§5 呈裁 4）。

**成立性判据 = probe 链 P-A/B/C/D（§4）**，此处只给机理预判（**预判非结论，probe 是唯一判据**）：

- med vs hard 差面分解（同深度、固定 depth 口径）：**预期以 QS 有无 + eval 叶差为主要棋力面**（v1.1 P3-①措辞收窄：原"仅有的两个棋力面/剪枝面零棋力贡献"过强——unsafe pruning 类如 LMR/razor 会改变选点，非严格零贡献；预判已显式非判据）——nullmove 门控 depth≥3（KI-2026-0925 亲验口径），d2 下零贡献；PVS/countermove/razoring/IDS 对固定深度棋力的直接贡献预期次要。
- 因此 **X₂ ≈ QS 战术视野差 + eval 差在 d2 的表达**。d2 恰在"看见对方回应"的边界，QS 缺失的水平线效应在此深度不该小——预判 X₂ 几十到一百出头，方向为正（med 弱）。
- **X₃（d3 口径）预计 > X₂**（更深树上 eval/QS 差被放大）——这对 Y2' 是双向刃：X₃ 大利好 L4→L5 段距，但逼近 269 时 C 段（med-d3 vs hard-d2）倒挂风险上升。
- 主要失效模式：X₂ < 40（QS 差被 eval 主导淹没）→ config 桥在 d2 失效，转混合/收缩路由。

### 2.2 Q2：798/269 断崖下五档用户梯度是否可达

**分口径回答：**

1. **均匀带内五档（四段全落 40-200）：不可达。** 数学：需 4 段单调档距，齿轮最多 3 段；且 L1→L2 段无论排什么（最低 med-d2）都是 ≈798−X₂ 的断崖，X₂ 窗口填不平 798。**收缩为五档均匀梯度的任何尝试都不必再做。**
2. **单调可感知：现成锚 = 三档 fallback；五档形态待 probe（v1.1 P2-2①改写，防误读）**。单调+可感知的现成锚 = §5.1 单调性硬门 + 档距门（≥40）/顶档差下限（≥50）——非 v1.2 §2（该锚系 depth 标签口径，P2-2③错锚订正）。**现在成立的命题 = 三档（d1/d2/d3，即 fallback）单调可感知；五档单调可感知的成立主体 = Y2' 排布的探测中形态**，不成立"无需 probe 即五档"。另按实录订正（P2-2②）：断崖 ≤200 系验收七条明文之一（draft §5.1/v1.4 门槛总览），非单纯设计带宽；Y 批表实测处置实录 = G1'/G3' 判"档距成立+断崖披露"，**停线主因 = B/K 方向门 + 单调硬门**，非断崖本身。
3. **带内四校准档 + L1 教学档豁免：条件可达（Y2'）。** P0 实测（双侧 39/40 走满和棋，v1.1 P2-4 精确口径）已证 L1 在 AI-AI 域无区分度（97.5% 无分出胜负，论证较 20/20 口径更强）——继续把 L1 当难度校准档是伪命题；反过来，**豁免 L1 后校准域缩为 L2-L5 四档，恰好是交错排布可覆盖的范围**。条件 = probe 链判定矩阵全过（§4）。

**对"收缩目标（三档/两极）"的态度：**

| 选项 | 判定 | 依据 |
|---|---|---|
| 两极 | **不推荐** | 等于放弃 v6.5 弱化链全部目标（五档梯度是立项前提），且 269/798 本身就是可用的"两极+中间"素材，没理由自砍到零梯度 |
| 三档（hard-d2/d3 + L1 或全 hard d1/d2/d3） | **合理 fallback**，非首选 | 零新工单零 probe 即可收口；代价 = 产品档位 −2、断崖成 产品明面特性、L1 语义仍需处置 |
| Y2'（五档产品面保留 + 校准面收缩为四档） | **首选** | 不损失产品档位；把校准承诺收缩到齿轮能支撑的范围；probe 失败时自然退化为三档，**下行风险有底** |

### 2.3 Q3：Y2' vs Y3 vs v2.2 重设计

**Y3：出清（当前无适用面）。**
- Y3 的原始触发条件 = "分支 Y 选取后 lvl1 depth1 完成性不达标"（draft 风险表 L233）。**P0 已实测排除该前提**（双侧全门 PASS，完成性无虞）。
- Y3 手段（撤库+撤 checkExt 再弱化）方向与三问正交：L1 已是梯度最弱端，再弱只放大 L1→L2 断崖；且 L1 一经豁免就退出校准域，弱不弱化与档距无关。
- 保留价值：若洪涛从产品面要"新手必胜教学档"，Y3 手段可复用为产品选项——但那是产品功能单，不属本路由决策，不入方案。

**v2.2 重设计：兜底保留，不并行。**
- 新轴存量全灭：N（X/Y 双分支双双出局）、B（−241 反向）、K（三点非单调）、预算（死轴）、topK（bestMove 路径无池，产品化成本升级）、nullmove R 参数化（需新参数，红线域）。**v2.2 的可行解空间与 Y2' 高度重叠**——剩下来的活齿轮就是 config×depth 的格子组合，重设计一轮（Vera 全审链 1-2 周）换不来新信息。
- 若终局走到 v2.2，正确口径是"**接受断崖的标签面收缩设计**"（即三档/带断崖披露的四档的文档化收口），不是"继续找轴"。
- 唯一实质新面 = 规则域弱化（让子/让先——产品成熟、语义清晰、用户可感知），但它是产品功能需求，超出 v6.5 引擎弱化链边界；若洪涛有意，另立产品单，不混入本收口。

**推荐序：Y2'（probe 先行）→ 三档收缩（probe 败）→ v2.2（仅当洪涛对三档不满意且愿付全审链成本）。**

## 4. probe 链设计（P-A/B/C/D，四批 80 局，一晚口径）

**硬前置**：SelfPlayRunner 双侧 config×depth 交叉注入探针（§2.1，Cody 探针工单，呈 Luke 派工）。

| 批 | 对局 | 单差 | 服务判据 |
|---|---|---|---|
| P-A | mediumNoQS-d2 vs hard-d2 | config（d2 域） | X₂：L2→L3 段距（丹妮点名件） |
| P-B | mediumNoQS-d3 vs hard-d3 | config（d3 域） | X₃：L4→L5 段距 |
| P-C | mediumNoQS-d3 vs hard-d2 | 交错差 | **C：L3→L4 段距 + 序验证**（>0 = 交错链成立；≤0 = 倒挂出局）——直接实测，不做 269−X₃ 推算 |
| P-D | hard-d2 vs hard-d3 | depth（**无库口径**） | D₂₃：主链无独立信息（C+X₃≡D₂₃ 路径恒等，可加性假设下）；**实际承重面 = ① fallback（三档）的 hard-d2→hard-d3 段距门（≥40/≤200）② 可加性旁证（\|C+X₃−D₂₃\| 显著非零 → 单差分解失效，全案复判）**（v1.1 P2-3 补职能） |

**口径**（沿 v1.4 全量）：n=20/批；库 off 双侧、kill off 双侧；预算 2000ms 护栏；moveLimit=300；级别视角归账（KI-2026-0922-02 修法 A）；分派判据走奇偶角色推导（KI 同族规约，禁难度恒等式）；纯计算时钟；门槛集 = 方向（>0）/ 档距（≥40，40-50 加赛 n=60）/ 断崖（≤200）/ 显著性（CI 不含 0）/ 平局率（>40% 加赛 15 局）。

**判定矩阵**：

| probe 结果 | 路由 |
|---|---|
| C>0 且 X₂∈[40,200] 且 X₃∈[40,200] 且 C∈[40,200] | **Y2' 成立** → 档位表 §3 定稿，呈洪涛终裁 |
| C≤0（med-d3 不强于 hard-d2） | 交错废 → L2-L5 收缩为 hard-d2/med-d3?/hard-d3 线性链或直接三档，呈裁（**fallback 段距门由 P-D 承载**） |
| \|C+X₃−D₂₃\| 显著非零（可加性破） | 单差分解失效，全案复判（v1.1 P2-3 补行） |
| X₂<40（config 桥 d2 失效） | 混合形态：config 桥只承担 L4→L5（若 X₃ 达标）→ 四档变三校准档 + 教学档；或全败则三档 |
| 边缘带（任一 40-50） | 该段加赛 n=60 提精度后复判（v1.4 机制沿用） |
| 全部失效 | 三档收缩呈裁；v2.2 仅当洪涛明确不接受三档 |

**估时**：探针工单 ~0.5d 内 + 80 局一晚（P0-macOS 步时 8.4ms 基准下，d2/d3 对局均值分钟级/局，参照 G 链四批 13 分钟实录）→ **批准确认后 T+2 日内可收口判定**。
