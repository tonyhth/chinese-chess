# v2.3 需求 backlog（商业交付后）

> 来源：v2.2.16 商业交付检查（R3-07）遗留问题
> 日期：2026-06-15
> 状态：待规划

---

## 需求 1：打谱功能（P1）

**背景**：竞品 A/B/C 均支持加载外部棋谱文件进行浏览/编辑/学习，我们目前只有自己对局的回放，进阶用户缺少学习工具。

**功能描述**：
- 支持加载标准棋谱文件（PGN/XQF 格式）
- 逐步浏览棋谱（前进/后退/跳转）
- 棋谱编辑（添加注释、变着）
- 打开经典棋局库（可内置名手对局）

**优先级**：P1
**建议版本**：v2.3

---

## 需求 2：引擎分析（P1）

**背景**：竞品 C（Xiangqi.com）有完整的引擎分析功能。我们已有 Alpha-Beta 搜索+评估函数，扩展成本低。

**功能描述**：
- 复盘模式下，AI 实时评估当前局面，给出优劣势评分
- 标注"最佳走法"建议（可叠加在棋盘上）
- 走法质量分级（好棋/疑问手/漏着）
- 深度可调（快速分析 vs 深度分析）

**优先级**：P1
**建议版本**：v2.3
**技术评估**：基于现有 AI 引擎扩展，核心逻辑已有，主要是 UI + 分析模式交互设计

---

## 需求 3：PuzzleRow VoiceOver accessibilityLabel 补充（P2）

**背景**：R2 代码审查发现残局选择列表的星级和通关标记对 VoiceOver 用户不可读。

**功能描述**：
- 给 PuzzleRow 添加显式 accessibilityLabel
- 格式：「{棋名}，难度{N}星{已通关/未通关}」
- 使用 `.accessibilityElement(children: .combine)` 合并子元素

**优先级**：P2
**建议版本**：v2.2.17 patch 或 v2.3 顺手修
**工作量**：~10 分钟

---

## 需求 4：开局库加权随机用户可见化（P2）

**背景**：开局库 4602 位置、1441 个位置有 2+ 走法、加权随机选择——技术上比竞品好（竞品固定开局），但用户完全感知不到这个差异。

**功能描述**（可选方案，择一）：
- **方案 A**：状态栏/记谱面板标注当前开局名称（如"中炮局"、"仙人指路"、"飞相局"）
- **方案 B**：统计页加"开局多样性"指标（已使用过 N 种开局变化）
- **方案 C**：设置页加"开局随机化"开关 + 说明文案，让用户知道功能存在

**优先级**：P2
**建议版本**：v2.3
**备注**：方案 A 最直观但需要开局名称映射表；方案 C 最低成本

**背景**：竞品 A/C 均有在线对战功能，是社交型用户的核心需求。

**功能描述**：

**优先级**：P1
**建议版本**：v3.0（需要后端基础设施，工程量大）
**备注**：不在 v2.3 范围内，需单独规划
