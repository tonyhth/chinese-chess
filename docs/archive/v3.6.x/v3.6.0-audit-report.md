## Key Gaps & Recommendations

### 🔴 High Priority

1. **No PositionAnalyzer unit tests** — Phase 1 core logic (evaluate, topMoves, classifyMove, MoveQuality) has zero dedicated test coverage. This is the foundation for Phase 2-3.
2. **No PuzzleChapter/ChapterStore unit tests** — Design doc explicitly lists `PuzzleChapterTests.swift` as expected. Chapter partitioning (551→7 chapters) and unlock logic are untested.

### 🟡 Medium Priority

3. **No OpeningTreeNode unit tests** — Tree construction from opening_book_v2 is untested.
4. **Retired achievement display** — `Achievement.retired` set exists but no test verifies UI renders them as "已退役".
5. **CoachModeOverlay UI testing** — No test for the overlay's hint/detail/skip flow.
6. **Daily challenge integration tests** — 3 modes are defined but integration with GameViewModel (blitz timer, master challenge no-penalty) is not verified.

### 🟢 Low Priority

7. **Q5 (金币经济) not implemented** — Acceptable per design doc (optional).
8. **App icon design** — Design doc requires AppIcon.appiconset per AGENTS.md; not verified in code audit (design-time artifact).
