## 具体实施内容

### 5.1 新手引导（5 步互动教程）

**第 1 课：棋子走法**
- 交互式：点击每种棋子，高亮合法走法
- 覆盖：将/帅、士/仕、象/相、马、车、炮、兵/卒
- 特殊规则展示：马蹩脚、象塞眼、炮翻山
- UI：棋子列表 + 棋盘演示区 + "下一步"引导

**第 2 课：将军与应将**
- AI 走一步将军棋，玩家选择应将方式
- 展示：垫将（放子阻挡）、避将（移将）、吃掉攻击子
- 设计 2-3 个预设场景

**第 3 课：将死判定**
- 3 个简单的 1 步杀题目
- 过关提示："你已掌握将死！"
- 错误时高亮对方将军子 + 解释为什么无法应将

**第 4 课：特殊规则 — 困毙与和棋**
- 困毙（无合法走法且未被将军）→ **判负，不是和棋**（中国象棋与国际象棋的关键区别）
- 和棋情形：双方同意和棋、长将和棋（连续将军需变着，不变判和）、长捉和棋
- 简单交互展示每种情形

> ⚠️ **设计注意**：中国象棋的困毙规则与国象完全不同。国象 stalemate=draw，象棋 stalemate=**loss**。教程文案必须明确区分，避免误导新手。

**第 5 课：第一局实战**
- AI 降至最低难度（beginner）
- 关键局面高亮推荐走法（浅色箭头提示）
- 完成后获得"初出茅庐"成就 + 升至学童段位

**触发机制**：
- 首次启动：弹窗"是否熟悉中国象棋规则？"
- 选"否"→ 进入教程
- 选"是"→ 跳过，设置中保留"规则手册"入口
- 教程可随时从设置页重新进入

### 5.2 对弈选边

**当前状态**：默认执红，无选择 UI。

**升级内容**：
- 新对局设置页增加"执红先手 / 执黑后手"选择器
- 执黑时 AI 先行
- 记住上次选择作为默认
- 对局进行中不可切换

## 依赖关系

```
Phase 5（本阶段：新手引导 + 选边）
├── 无前置代码依赖（可与 Phase 1-4 并行启动）
├── 输出 → Phase 6（成就系统：教程完成触发成就）
├── 输出 → Phase 6（段位系统：教程完成升段位）
└── 可并行 ← Phase 1/2/3（AI 工作）
              Phase 4（NNUE 调研）
```

**并行标记**：
- Phase 5 完全独立于 AI 工作线，可由不同人员 Week 1 即启动
- Phase 5 与 Phase 6 有**分步验收**约定：
  - Phase 5 自身验收：教程可玩、`completedTutorials` 写入正确（Week 1-2 可独立验收）
  - 联动验收（依赖 Phase 6）：成就解锁、段位升级（Phase 6 完成后补充验收）
  - 接口约定：Phase 5 代码中调用 `AchievementManager.unlock(.firstStep)` 和 `PlayerProfile.checkRankUp()`，即使 Phase 6 尚未实现，用 protocol 占位确保接口兼容
