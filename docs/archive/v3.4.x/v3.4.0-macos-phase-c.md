## 详细实施

### C.1 EngineRouter 统一

**改动**：删除 `#if os(macOS)` 外部进程分支，统一使用 `EmbeddedPikafishEngine`。

```swift
// 之前：macOS 和 iOS 分开处理
#if os(macOS)
private var externalEngine: (any ChessEngine)?
private var currentConfigId: UUID?
#endif
#if os(iOS)
private var externalEngine: EmbeddedPikafishEngine?
#endif

// 之后：统一（删除 #if os，iOS/macOS 共用）
private var externalEngine: EmbeddedPikafishEngine?

@MainActor
func activeEngine() -> any ChessEngine {
    if let ext = externalEngine {
        return ext
    }
    return nativeEngine
}

@MainActor
func switchEngineIfNeeded() async -> any ChessEngine {
    let store = EngineConfigStore.shared
    if store.useEmbeddedEngine {
        if externalEngine == nil {
            externalEngine = EmbeddedPikafishEngine()
            try? await externalEngine!.start()
        }
        return externalEngine ?? nativeEngine
    } else {
        if let ext = externalEngine {
            await ext.shutdown()
            externalEngine = nil
        }
        return nativeEngine
    }
}
```

> **线程安全说明**：`EngineRouter` 标记 `@MainActor`，所有方法在 MainActor 上执行。从非 MainActor 上下文调用 `switchEngineIfNeeded()` 时，Swift 自动 hop 到 MainActor。

### C.2 EngineConfigStore 简化 + 重命名

**文件重命名**：`ExternalEngineConfig.swift` → `EngineConfigStore.swift`

**删除**（外部引擎配置管理）：

```swift
// ❌ 删除以下属性
// var engines: [ExternalEngineConfig]
// var selectedEngineId: UUID?
// var pendingEngineId: UUID?
// var pendingNative: Bool
// var wantsExternalEngine: Bool
// var hasPendingSwitch: Bool
```

**保留**：

```swift
// ✅ EngineConfigStore.swift
import Foundation

class EngineConfigStore: ObservableObject {
    static let shared = EngineConfigStore()

    @Published var useEmbeddedEngine: Bool {
        didSet {
            UserDefaults.standard.set(useEmbeddedEngine, forKey: "chinesechess.useEmbeddedEngine")
        }
    }

    private init() {
        useEmbeddedEngine = UserDefaults.standard.bool(forKey: "chinesechess.useEmbeddedEngine")
        migrateLegacyConfig()
    }

    /// 迁移旧 UserDefaults 数据
    private func migrateLegacyConfig() {
        let defaults = UserDefaults.standard
        let legacyKeys = [
            "chinesechess.externalEngines",
            "chinesechess.selectedEngine",
            "chinesechess.pendingEngine"
        ]
        for key in legacyKeys {
            if defaults.object(forKey: key) != nil {
                defaults.removeObject(forKey: key)
            }
        }
    }
}
```

### C.3 UserDefaults 迁移

`migrateLegacyConfig()` 在 `EngineConfigStore.init()` 中自动执行：
- 清理旧 key（`chinesechess.externalEngines`、`selectedEngine`、`pendingEngine`）
- 确保新代码不会意外读取旧配置
