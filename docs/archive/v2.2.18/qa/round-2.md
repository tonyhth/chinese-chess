## 1. 交互直觉性

### 1.1 走棋操作

**当前实现**：`ChessBoardView` 使用 `onTapGesture { location in handleTap(...) }` 处理点击。

| 操作 | 实现 | 评估 |
|------|------|------|
| 选子 | 点击棋子 → `selectPiece(at:)` | ✅ 直觉：点击选子是标准交互 |
| 走子 | 选中后点击目标格 → 再次 `handleTap` | ✅ 直觉：两步点击模式 |
| 取消选中 | 点击空位/非合法位置 | ✅ 合理 |
| 拖拽走子 | 不支持 | ⚠️ P1：商业化象棋 App 普遍支持拖拽，缺少可能影响用户评分 |

**R2-01（P1）：不支持拖拽走子**

- **文件**：`ChessBoardView.swift:77`
- **现状**：仅 `onTapGesture`，无 `DragGesture`
- **影响**：多数用户首次操作会尝试拖拽，失败后需学习点击模式。移动端尤其明显。
- **修复建议**：
  ```swift
  // 交互层添加 DragGesture（与 onTapGesture 并存）
  .gesture(
      DragGesture(minimumDistance: 10)
          .onChanged { value in /* 实时拖拽视觉反馈 */ }
          .onEnded { value in handleDrag(from: value.startLocation, to: value.location) }
  )
  ```
- **工作量**：中（需处理拖拽中棋子跟随手指的视觉反馈）

### 1.2 悔棋操作

| 平台 | 入口 | 快捷键 | 评估 |

| macOS | ToolbarView "悔棋" 按钮 | ⌘Z | ✅ 完整 |
| iOS | ToolbarView "悔棋" 按钮 | — | ✅ 合理 |

**R2-02（P2）：悔棋按钮 disabled 时无视觉区分**

- **文件**：`ToolbarView.swift`
- **现状**：`.disabled(viewModel.isThinking || viewModel.board.moveHistory.isEmpty)` — 按钮变灰但无文字说明为什么不能悔棋
- **影响**：用户可能不理解为什么悔棋按钮不可用（AI 思考中 vs 无棋可悔）
- **修复建议**：添加 `.help()` (macOS) 或 accessibility hint 说明禁用原因
- **工作量**：极小

提示视觉反馈：蓝色圈（起点）+ 蓝色实心圆（终点）。✅ 清晰可辨。

**R2-03（P2）：提示结果无文字说明**

- **文件**：`ChessBoardView.swift` renderOverlays + `GameViewModel.swift`
- **现状**：提示仅以视觉标记显示（蓝色圈+圆），无文字消息如"建议：車一平五"
- **影响**：新手可能不理解蓝色标记的含义
- **修复建议**：在 StatusBarView 中短暂显示提示文字（3 秒后消失）
- **工作量**：小

### 1.4 残局交互

**R2-04（P1）：残局无目标说明**

- **文件**：`PuzzleSelectView.swift` PuzzlePlayView
- **现状**：标题栏仅显示残局名称和步数计数器，不显示目标（如"红先胜"、"三步杀"）
- **影响**：用户不知道要达成什么目标（将杀？吃光？还是达到某种局面？）
- **修复建议**：在标题栏或棋盘上方添加目标提示，如"目标：红先将杀（限 N 步）"
- **工作量**：小

## 3. 错误提示

### 3.1 非法走法

**当前实现**：点击非合法位置时无反馈。棋子取消选中。

**R2-08（P1）：非法走法无任何提示**

- **文件**：`ChessBoardView.swift` handleTap → ViewModel selectPiece/handleSquareTap
- **现状**：点击不合法的目标格，棋子取消选中，无文字/音效/震动反馈
- **影响**：新手不知道为什么棋子不能走到那里（被挡？蹩马腿？将帅对面？）
- **修复建议**：
  1. 选中棋子后，点击非法目标格时显示简短原因（如"蹩马腿"、"被挡"）
  2. iOS 端添加轻微震动反馈（`UIImpactFeedbackGenerator`）
  3. 或至少保持选中状态不变，不取消选中，让用户重新选择
- **工作量**：中（需要识别非法走法原因，需要走法验证器返回原因枚举）

### 3.2 网络错误

**当前状态**：App 完全本地运行（无网络请求），不存在网络错误场景。✅

### 3.3 残局超步
