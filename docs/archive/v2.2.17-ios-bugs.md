## Bug 列表

### Bug 1：残局失败后点击重试无法走子
- **现象**：残局挑战失败后，点击"重试"按钮进入新局，但棋子无法移动
- **疑似模块**：`PuzzleViewModel.swift` / `GameOverOverlay.swift`
- **排查方向**：重试后游戏状态未正确重置（isPlayerTurn / gameOver flag / 棋盘状态）；GestureRecognizer 可能未重新启用
- **严重性**：P0 — 用户无法继续游戏

### Bug 2：设置页面进入后没内容
- **现象**：点击设置入口，页面空白或内容未渲染
- **疑似模块**：`SettingsView.swift`
- **排查方向**：iOS 下 NavigationLink / sheet 展示是否正确；SettingsView body 是否有条件渲染导致内容被跳过；iOS 与 macOS 的视图分支差异
- **严重性**：P0 — 用户无法访问设置功能

### Bug 3：历史对局选中后不显示
- **现象**：在历史对局列表中选中一条记录，但棋盘/回放内容不显示
- **疑似模块**：`GameHistoryStore.swift` / `ReplayView.swift` / `ReplayViewModel.swift`
- **排查方向**：选中后数据加载是否正确（GameRecord 解码 / 棋谱解析）；ReplayViewModel 的 loadGame 方法是否在 iOS 下正确触发；NavigationLink 目标视图是否正确绑定
- **严重性**：P0 — 回放功能不可用

### Bug 4：中级 AI 有时思考时间太长
- **现象**：中级难度（Intermediate）某些局面下 AI 思考时间过长，用户体验差
- **疑似模块**：`AIEngine.swift` / `TimeManager.swift`
- **排查方向**：中级难度的搜索深度设定值；TimeManager 超时机制是否生效；某些局面（如大量吃子）导致搜索树爆炸；是否缺少迭代深化的时间截断
- **严重性**：P1 — 影响体验但不阻塞功能

### Bug 5：不知道自己选的哪个级别
- **现象**：用户选择难度后，界面上没有明显标识当前所处难度等级
- **疑似模块**：`StatusBarView.swift` / `SettingsView.swift` / `ToolbarView.swift`
- **排查方向**：当前难度是否有 UI 展示（状态栏/设置页选中态）；难度选择器是否有选中标记；是否缺少难度名称的持久化展示
- **严重性**：P1 — 体验问题，用户困惑
- **建议**：在状态栏或棋盘显著位置标注当前难度等级（如"中级"badge）

### Bug 6：棋谱记录不工作
- **现象**：对局过程中棋谱没有正确记录或展示
- **疑似模块**：`RecordPanelView.swift` / `GameViewModel.swift` / `GameMove.swift`
- **排查方向**：走子后是否正确追加到 moveHistory；RecordPanelView 是否实时刷新；iOS 下 ScrollView/List 的数据绑定是否正确；棋谱格式化逻辑是否有条件分支问题
- **严重性**：P0 — 核心功能缺失
