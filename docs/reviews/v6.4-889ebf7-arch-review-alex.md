## ② calibrationVersion 钩子接线 —— 与定案锚口径不一致，校准落地窗口有缺口（P1）

**定案锚**（`8dd48a7`，T-0917-7 1c）：趋势对比前 `filter { $0.calibrationVersion == StrengthReport.currentCalibrationVersion }`——**全局常量为过滤基准**；"nil=legacy 恒 false"（legacy 不参与趋势）。

**实现**（`889ebf7`，AssessmentStore.swift:39-56）：`previousReport` 以 **cur（最新报告自身版本）** 为基准过滤同版本序列；消费侧 `AssessmentView.swift:71` 直接 `if let prev = previousReport` 出趋势箭头，**未挂 `isCurrentCalibration` 门控**。

**测试覆盖**（C4bCalibrationHookTests 四测）：同版本序列 ✓、跨版本隔离（legacy 为**非最新**）✓、混合跳版本 ✓、判定面 ✓——覆盖良好但两个窗口未覆盖：

| 窗口 | 情形 | 定案锚行为 | 实现行为 |
|------|------|-----------|---------|
| W1 陈旧序列 | 常量递增（校准落地）后、新报告未生成前，最新报告仍 v1 | filter 对常量 → 空 → nil → **不显示趋势** | filter 对 cur(v1) → 返回 v1 前一份 → **显示旧 regime 内趋势**；此时 `isCurrentCalibration(latest)=false` 但无人消费该判定 |
| W2 legacy 最新 | 最新报告 calibrationVersion=nil | 恒 false → **不参与趋势** | nil==nil 匹配全部 legacy 报告成序列 → **legacy 之间显示趋势**（测试仅覆盖 legacy 为非最新） |

**当前生产影响**：常量=1 未递增，v1 序列内趋势同 regime 真实可比，今日无伪趋势在产——故非 P0。但**该钩子存在的唯一目的就是校准落地窗口**：A3 校准批递增常量的瞬间 W1 打开。**分级 P1：校准落地批合入前必须二选一闭环—— 消费侧挂 `isCurrentCalibration(report)` 门控（改动最小，AssessmentView:71 一处）； previousReport 过滤基准改回全局常量（贴定案锚原文）。** 建议，与定案锚逐字一致且 W1/W2 同时闭合。
