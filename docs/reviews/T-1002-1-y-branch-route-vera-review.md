## 三、问题清单

### P1-1 单差链原则自洽矛盾（v0.5 必修，文字修）

**位置**：§1.3 vs §3/§4。
**问题**：§1.3 用"违单差链（§Y v0.4 重设计的立身原则）"否定原 Y2 的 d2 态；而 Y2' 自身的 C 段（hard-d2→med-d3）同为 config+depth 双差（报告自己在 P-C 表中标"交错差"）。全文无区分论证——终裁读者第一问即命中："你的交错段不也是双差吗？"
**修法**（三件套）：
1. 原则精化为"**每段主差单一，或整段直测**"——C 段归因由 P-C 实测直接承载、不依赖轴分解推算。这正是 P-C 取代 269−X₃ 推算的方法论价值（§2.1 已有素材，串成显式豁免条款即可）。Y2' 恰好只有 C 段一个豁免段，是最小偏离。
2. §1.3 对原 Y2-d2 态的否定改由断崖论证独立承载（L1→L2 ≈ 798−X₂ >> 200），"违单差链"措辞删换，零结论损失。
3. R6 的 draft v0.5 范围扩充：draft L142 单差链原则表述同步修订（现文本"逐档单差链"无直测豁免条款）。

### P2-1 齿轮算术：双框架未声明，不可达论证需按修正框架重述

**位置**：§1.2、§2.1 Q2-1。
**问题**：§1.2 前半"config 一台阶、最多 3 段"按**严格单差链**口径自洽（二值 config 从弱到强只升一次，3 边 4 格封顶）；后半交错排布的 3 段（X₂/C/X₃）中 C 是交错段——已在"整段直测"修正框架下工作。同段双框架未声明，且 P1-1 修正后："直测框架下 5 格链**存在**"（如 med-d1→hard-d1→hard-d2→med-d3→hard-d3，恰含一条 d1↔d2 边），"最多 3 段"不再是排布空间的正确界。
**真正的承载论证**（结论不变）：任何 5 格链必含恰一条 d1↔d2 边——hard-d1→med-d2 = 798−X₂，或 med-d1→med-d2 = 798−X₂+X₂@d1（按报告自证 X₂@d1<40、X₂≤200，下界 ≈598）——均为断崖，带内四段不可达成立。
**修法**：v0.5 按修正框架重述：严格单差链下 3 段封顶；直测框架下 4 段链存在但必含 d1↔d2 断崖边（给出上述下界算式）。结论（带内五档不可达 / Y2'=最大校准域）不变。

### P2-3 P-D 批次判定职能缺失

**位置**：§4 判定矩阵。
**问题**：矩阵全部判定行由 C/X₂/X₃ 承载；P-D（D₂₃_hard）在 Y2' 主链无独立信息（路径恒等式 C+X₃ ≡ D₂₃_hard，纯可加性下零增量）。四批 80 局中 20 局的产出无判定归宿。
**P-D 实际承重面**（矩阵未编码）：
1. **C≤0 / 三档 fallback 的段距门**：三档收缩（hard-d2/d3）的 L3'→L4' 段距 = D₂₃，需过 ≥40/≤200 判定——这是 fallback 分支的承重测量；

**修法**：矩阵补 P-D 判定行（上述两条）；若决定只作旁证不设门，明示其地位并可评估砍批省 20 局（**建议保留**——fallback 承重）。
