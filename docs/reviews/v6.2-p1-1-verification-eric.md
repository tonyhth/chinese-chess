## 真问题详情：双通道竞态

```
message = "已降级至业余X级"（非 nil）
  ├─ 通道 B（ToolbarView, v3.4.0）：onChange 触发 → toast 显示 2s → message = nil  ← 先到
  └─ 通道 A（App alert, v6.0 c767627）：isPresented binding get { message != nil } → 已被清空 → false
```

- alert binding 需持续 true 至呈现完成；onChange 在同一 render cycle 同步清 nil → alert 几乎必然不呈现
- 用户实际体验（双平台）：2 秒 toast——**P1-1 声称的"用户零感知"痛点实际不存在**（toast 已覆盖）
- 次要冗余（P2）：GVM:685-690 通知监听 set + 手动 set 同值双写
