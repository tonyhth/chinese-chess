## 三、范围裁定（2 处偏离 Vera 基线，实测定）

**3a. ChapterSelectView 出统一范围（豁免）**
Vera A3 基线称"7 视图全有空态分支"。实测 ChapterSelectView **无页面级空态**：
- 章节列表 `ForEach(store.chapters)` 为结构性必有（store 恒非空），无 isEmpty 分支
- `demoPuzzleCount == 0` 的 `DemoEntryCard(0, 0)`（:36-37）是**功能入口降级**（入口卡恒在，仅计数归零），语义是"入口仍在、演示未解锁"，非"无内容"
- 强行套 CUV 会把功能入口错改为无内容提示——语义错误。建议豁免，请 Luke/Ruby 确认

**3b. MGBV :484 零改动**
已是 CUV 双参形态（title + systemImage），即本单统一目标形态。无 description key（master.search.noResult 无配对 hint），按"复用既有 key"原则不造新 key，维持零改动。

## 四、替换设计（5 视图）

统一模式（CUV 闭包形态，承载全部三通道）：
```swift

    Label(l10n.t("<title.key>"), systemImage: "<icon>")
} description: {
    Text(l10n.t("<hint.key>"))   // 有 hint key 者保留

// OpeningExplorer 独有 actions: { Button(l10n.t("common.close")) { dismiss() } }
```

| 视图 | 设计要点 |
|------|---------|
| GameHistory | icon/title/hint 全保留原值 |
