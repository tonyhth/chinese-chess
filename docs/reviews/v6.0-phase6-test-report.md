### 与设计文档 §2.3 一致性

| Elo 差 | 设计文档判定 | 实现结果 |
|---|---|---|
| < 100 | 6 级上调到 Skill 7 | ✅ |
| 200-400 | ✅ 确认 Skill 5 | ✅ |
| 400-800 | 6 级下调到 Skill 3 | ⚠️ 实现为 > 500（非 400）|
| > 800 | 启用 Plan B | ⚠️ 实现为 > 500 → Skill 3 |

**说明**：实现的阈值（>500 → Skill 3）与设计文档（>400-800 → Skill 3, >800 → Plan B）略有差异。实现采用了更简单的两段式（<100 / 200-400 / >500），省略了 Plan B。这不影响功能正确性，但与设计文档有偏差。
