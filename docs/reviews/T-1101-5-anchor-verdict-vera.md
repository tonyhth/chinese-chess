## 二、裁①：单 punish 四断言互斥机理——成立

### 2.1 依据链（四条独立收敛）

- **推导（域内代数，定义级）**：应将族由合法性定义约束——所有应将手必须解将（捕将子/挡线/移将），故**响应生成集≡防守集**（「造响应子=防守子」是定义级推论而非经验归纳）。A1（应将≥9）要求黑宫区防守子富集（富军）；A2（top8 全败）要求红以单一 punish 机制在每诱饵后强制赢——单机制击穿富军的资源不等式两侧不可同时成立。A3 侧加压：唯一活手须「解将∧破 punish」双职能，其评分载荷（邻近/阻挡/捕将分）天然落高分带，与「排位≥9」相斥——即 Tina §八两约束（无捕将响应+破杀应将排位≥9）的代数根源。
- **实证**：五扫 9892 变体 0 命中（谱系见 §五）——手摆（A1 6）+curated（B1 336/B2 5544）+生成式（B3 FAST 2003×2）三形态全覆盖单 punish 族。
- **判据可信**：mirrorScore 三项代数 Ruby 已验逐项与源码 :101-140 一致（走子方己将邻近/对手攻击线阻挡/走前盘面计数）→ 0 命中非镜像伪影。
- **旁证族**：v1/v2/v3 三败根因谱系（5.5 审计 §二）＋车将 cascade/行0围城/双炮结构推演否决记录＋既有锚实测排序 150/160/140（救活手必落前 8 窗口）——全族同向收敛。

### 2.2 域界声明（关键限定）

「四断言在**单 punish 结构内**互斥」成立；**不可外推**为「四断言全局不可满足」。multi-punish 族未探测、未被证伪——这是路线一的逻辑领地，不构成推翻机理的依据（机理命题的域限定即单 punish）。本裁定据此把「禁扫令」与「域界」分开处理（见 3.4）。

### 2.3 反例方向探测记录（为何无推翻）

本轮独立构造测试三条反例方向，全部收敛回同一堵墙：
1. **毒饵捕获族**（黑富攻击军以捕红毒饵生成 8+ 高分诱饵）——可被捕毒饵须为将子（解将合法性），捕将 baseValue 必排前 8，旧代码必绿；
2. **单一不可抗拒威胁+唯一覆盖手**——覆盖手必近己将或捕威胁子，评分落高分带排位必前 8；
3. **远近插子不对称+行列巡逻保护点阵**——近插诱饵的再捕获成片受保护需 punish 网覆盖多几何，单机制覆盖多几何=multi-punish（域外）。

无一能既保 A1 富军又保 A2 全败且 A3 排位≥9。**推翻不成立，维持 lead 工作裁定。**

### 3.2 路线二口径修正（P1 级纠偏）与可交付形态

**纠偏**：原设想「prefix(8) dfs 克隆新旧判定直接断言分歧（不需作曲位面）」隐含前提错误——差分断言要成立，必须存在「旧判杀∧新判非杀」的**分歧见证局面**；其充要条件恰=四断言全绿（top8 全败∧rank≥9 活手∧根非杀），**与作曲问题同构**。单 punish 域内见证局面被机理+五扫封死；multi-punish 域内=路线一的作曲问题。「克隆」只解决旧判定从哪来（git e93ccc11^ 历史/测试镜像），不解决见证局面从哪来。**不修正则路线二落成「跑在无分歧局面上的永绿假差分」。**

**可交付形态=判定循环语义钉（loop-semantics pin）**：
- **实施面**：CheckmateSearch 响应校验循环开最小 release-safe 测试缝（`#if DEBUG` 内部 hook 形态，Release 编译剔除=语义恒等——先例=T-1101-1 件3② GameRecordStore 缝五点裁定框架：Release 恒等/tests-only 替代不存在/最小路径）。
- **夹具**：**复用既有锚局面**（nineResponsesFullValidationContract 的 10 应将面——真实合法局面，零作曲）。
- **断言口径（验收四条）**：①注入受控 oracle（前 8 次调用判「红赢=败着」、第 9 次起判「黑活」——覆盖 dfs 逐应将递归调用位）后 `search == nil`（截断回潮时前 8 全胜→判定翻 mate→断言红）；②oracle 调用计数 **≥9**（新代码在首个活手早退属正常语义，断言下界=9 即「越过旧 prefix(8) 窗口」；截断回潮时 ≤8 必红）；③判别力自证（可选）：测试侧 prefix(8) 克隆循环喂同 oracle 断言其翻 mate——文档级对照，不承担生产门禁；④前置断言应将 ≥9 维持（夹具漂移门，:81 模式沿用）。
- **保护面声明（诚实披露）**：语义钉保护的是「全量校验循环语义」回归向量（prefix(k) 回潮/早退「优化」——750ms 全量成本压力是现实回归向量，fix 注记自认）；它**不证明战略层 FP 行为**（真实局面假阳性），后者只能靠作曲锚。**对 P3 强化资产目标，语义层判红已足够。**
- **实施链**（若 lead 批准立项）：Cody 落缝+语义钉测试→Ruby 审（缝 release 恒等五点框架）→Tina 验（runner 通道）→Luke 收口。预估小批（缝+测试+批跑，无战略层新面）。
