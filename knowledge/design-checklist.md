# 方案审查清单

## 完整性
- 数据模型是否完备（主键、外键、索引、软删除字段）
- API 设计是否覆盖所有 CRUD + 批量操作
- 权限矩阵是否完整（每个角色 × 每个操作）

## 可行性
- 技术选型是否有验证依据（不是拍脑袋）
- 部署方案是否可直接执行（Docker Compose/CI/CD）
- 依赖服务是否都有健康检查和启动顺序

## 一致性
- 数据模型与 API 设计是否矛盾（如：软删除字段缺失）
- 安全机制是否端到端（不是只在前端做）
- 缓存策略是否明确（key 设计、TTL、失效机制）

## 工期合理性
- 工期评估是否基于具体任务拆分（不是拍数字）
- 是否考虑了联调、测试、文档时间

## 🚨 交付必备（Vera 审查时强制检查）
- [ ] App 图标设计（AppIcon.appiconset，各尺寸齐全，风格与项目 UI 一致）
- [ ] 图标已集成到 Xcode 项目 Assets.xcassets/AppIcon.appiconset/

> 没有图标设计 → 方案不完整，必须打回 Alex 补充。

## 遗漏检查
- [ ] 错误处理策略
- [ ] 日志/监控方案
- [ ] 数据迁移/回滚方案
- [ ] 性能基准或容量预估
